# Alvin Wambua – Personal E-Portfolio

A responsive personal e-portfolio website covering education, skills, projects, learning journey, interests and professional contact.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet is required for the optional Google Fonts; the site otherwise works as a static website.

## Publish free with GitHub Pages
Recommended: create a separate public repository named `alvin-wambua-eportfolio` under GitHub account `incognito-58`.
1. Create the repository without adding a README, license or `.gitignore`.
2. Upload the **contents** of this folder (`index.html`, `assets/`, and `README.md`) to the repository root.
3. Commit the upload.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. The site URL should be `https://incognito-58.github.io/alvin-wambua-eportfolio/`.

## Personalize before sharing
- Review every statement and ensure it remains accurate.
- Add a professional email address only if you want it public.
- Add verified certificates, awards, work experience and a CV when available.
- Add your own project screenshots only after completing the work; do not present planned projects as completed.
- The project links currently point to the GitHub repository `incognito-58/My-cybersecurity-Portfolio`. If you rename that repository, update the links in `index.html`.

## Edit content
Open `index.html` in a text editor. Search for the section headings to change text. Update colors and layout in `assets/style.css`.
